# Statistics From Scratch

Source for *Statistics From Scratch: An Introduction for the Social Sciences* by Rob Brotherton.

Render the book locally with `quarto render`. The published site is built from the `main` branch by GitHub Actions.

Corrections and bug reports are welcome through [GitHub Issues](../../issues).
